How “adequate” is defined

The fast analysis uses Fisher-derived uncertainty for each physiology × error state and a paired bootstrap across those states. A protocol is considered adequate when the upper 95% confidence bound for its ONP precision loss and shunt precision loss versus the largest-N reference both remain below the tolerances above. A difference can therefore be statistically detectable but still too small to justify another PETO₂ steady state.
