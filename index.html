What this version calculates

This is an ALPE-inspired reduced model for teaching and experimental-design exploration, not yet a validated reproduction of the proprietary/commercial ALPE implementation. The code deliberately isolates the physiology function so a full two-compartment mass-balance implementation can replace it later.

1. Represent low V̇/Q̇ by ONP

Pc′O₂ = PET O₂ − ONP

ONP is treated as the effective pressure loss between mixed alveolar/end-expired oxygen and end-capillary blood before shunt mixing.

2. Convert PO₂ to oxygen content

CO₂ = 1.34 · Hb · SO₂ + 0.0031 · PO₂

A Hill oxygen-dissociation curve is used in this prototype (P50 26.8 mmHg, n = 2.7).

3. Mix shunted venous blood

CaO₂ = (1 − s)Cc′O₂ + sCvO₂

Default Hb is 14 g/dL and mixed-venous saturation 75%; these are currently fixed constants in the source.

4. Recover ONP and shunt

θ̂ = arg min Σ [SpO₂obs − SpO₂model(PETO₂, θ)]²

The simulator uses a coarse-to-fine grid search, making the fitting behavior transparent and robust for two parameters.

5. Protocol optimization

I(θ) ≈ JᵀWJ + Iprior

The Jacobian J contains local derivatives with respect to ONP, shunt, and (when enabled) a subject-level saturation bias. The inverse information matrix approximates parameter covariance. PETO₂ error is propagated into effective SpO₂ variance through the local dSpO₂/dPETO₂ slope.

How to interpret the optimizer

  • Median ONP SE: typical local uncertainty across the requested physiology grid.
  • Worst ONP SE: protects against designs that work in normal lungs but fail at severe mismatch.
  • Median |corr|: correlation between fitted ONP and shunt; values near 1 indicate poor parameter separation.
  • Monte Carlo RMSE: end-to-end error after simulating measurement noise and refitting the nonlinear model.
Research-use caution: protocol choices from this prototype should not be treated as validated ALPE acquisition recommendations. Before using the optimizer to determine a study protocol, the reduced ONP model should be replaced or benchmarked against the full published oxygen-transport model and real RespirAct/pulse-ox data.
